# 🍽️ Zomato Restaurant Clustering – Machine Learning Project

## 📌 Project Overview

This project focuses on segmenting restaurants using Unsupervised Machine Learning techniques.

The objective is to group similar restaurants based on their characteristics, including cost, ratings, cuisines and customer engagement.

## 🎯 Objectives

- Analyze restaurant data and customer reviews.
- Perform data cleaning and preprocessing.
- Explore restaurant characteristics using EDA.
- Apply feature engineering and dimensionality reduction.
- Group similar restaurants using clustering algorithms.
- Compare clustering performance using evaluation metrics.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- NLP – TF-IDF
- Truncated SVD
- Joblib
- Google Colab / Jupyter Notebook

## 🤖 Machine Learning Algorithms

1. K-Means Clustering
2. Agglomerative Clustering
3. Gaussian Mixture Model (GMM)

## 📊 Model Evaluation

- Silhouette Score
- Calinski-Harabasz Score
- Davies-Bouldin Score
- Inertia
- Bayesian Information Criterion (BIC)
